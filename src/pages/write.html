    How publishing works

    1. Press Publish on GitHub. GitHub opens in a new tab (sign in if it asks).
    2. GitHub shows your new post. Press the green Commit changes… button, then Commit changes again.
    3. Wait about two minutes, then open your blog. Your post is there!
